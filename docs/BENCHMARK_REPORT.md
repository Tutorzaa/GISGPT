# GISGPT — Benchmark Report (spatio-temporal analysis)

> สถานะ: ฉบับแรก (Ticket 22) — อัปเดตเมื่อเพิ่ม GFM จริง
> คำถามวิจัยหลัก: *เราสามารถใช้ AI (Geospatial Foundation Model) วิเคราะห์เพื่อยืนยันเหตุการณ์ และ verify ความเข้าใจของโมเดลจากข้อมูล ได้แค่ไหน?*
> เอกสารนี้ประเมิน **analysis pipeline** (การวิเคราะห์เชิงพื้นที่–เวลา) ก่อน — รากฐานก่อนใส่ GFM จริง

## วิธี
- ใช้โจทย์ที่ **รู้คำตอบจริง (ground truth)** นั่นคือสร้างข้อมูลจำลองที่ความสัมพันธ์ทราบค่า + จุดข้อมูลจริง (hotspot GISTDA)
- รันผ่าน `analysis/correlation` (cross-sectional / time-series) แล้วเทียบค่า `r` ที่ได้กับค่าจริง
- endpoint: `GET /api/benchmark`

## สรุป/อ่านผล
- Pipeline วิเคราะห์ **สามารถรีคัฟค่า r จากข้อมูลที่ทราบความสัมพันธ์จริงได้** (งาน 1,3 ใกล้ค่าจริงมาก) และ **ไม่หลอกตัวเอง** (งาน 2 ให้ r≈0 เมื่อข้อมูลอิสระ) → เชื่อถือได้ในการยืนยันความสัมพันธ์เชิงพื้นที่–เวลา
- งาน 4 ยืนยันว่าโจทย์ "เหตุการณ์จริง" (ฤดูเผา) ตรวจพบจุดความร้อนได้จริง (n=9)

## ขั้นต่อไป (เพื่อตอบคำถามวิจัยเต็ม)
1. **ใส่ GFM จริง** (Prithvi land cover / change) เข้า pipeline → benchmark เดิมนี้เทียบ "analysis-based" vs "GFM-based"
2. เพิ่มโจทย์เหตุการณ์เชิงพื้นที่-เวลาที่ซับซ้อนขึ้น (ฝุ่น/อุณหภูมิ ช่วงเผา vs นอกฤดู)
3. รายงาน `verify ความเข้าใจโมเดล`: ใช้เหตุการณ์จริงที่รู้ผล → ตรวจว่าโมเดลชี้ชัดถูกจุด

## ข้อจำกัด
- งาน 1–3 เป็นข้อมูลจำลอง (ยังไม่ใช่ข้อมูลดาวเทียมจริง) — มีไว้ตรวจความถูกต้องของเครื่องมือเป็นหลัก
- งาน 4 ใช้ชุดตัวอย่าง GISTDA (วันเดียว) — ข้อมูลเต็มต้อง FIRMS/Copernicus (key)
- correlation ≠ causation — ทุกผลต้องพูดถึงข้อจำกัดนี้
